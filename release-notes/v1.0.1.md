Keys to Wealth™: Rent It or Own It v1.0.1 is a small polish update. Like v1.0.0, it's free and fully offline, with no ads, account, or tracking, and it requests no Android permissions.

## Changes
- The top app bar is now solid black. Before, it was slightly see-through, so text scrolling underneath showed faintly behind the title.
- Version 1.0.0 → 1.0.1 (versionCode 1 → 2).

No changes to the game, its content, or the privacy setup.

## Install
Download `WGRALGO-KeysToWealth-v1.0.1.apk` and install it. It installs straight over v1.0.0, because it's signed with the same key.
